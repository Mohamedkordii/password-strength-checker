# Password Strength Checker 

A simple Python tool that evaluates the strength of a password based on common security criteria and provides feedback on how to improve it.

## Features

- Checks password length
- Detects uppercase and lowercase letters
- Checks for numbers
- Checks for special characters
- Classifies passwords as Weak, Moderate, or Strong
- Provides suggestions for improving weak passwords

## How It Works

The program evaluates a password using five criteria:

1. At least 8 characters
2. Contains an uppercase letter
3. Contains a lowercase letter
4. Contains a number
5. Contains a special character

Each satisfied requirement increases the password score.

## How to Run

Make sure Python is installed, then run:

`python password_checker.py`

Enter a password when prompted.

## Example

Enter a password to check: Hello123!

Password Strength: Strong
